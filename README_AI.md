# Sandeep AI Assistant

This package adds a premium AI chat widget to the portfolio.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`.
3. Create `.env` from `.env.example` and set `OPENAI_API_KEY`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

## Render
Create a Web Service from this repository.
- Build Command: `npm install`
- Start Command: `npm start`
- Environment variable: `OPENAI_API_KEY` = your API key
- Optional: `OPENAI_MODEL=gpt-6-luna`

Never put the API key in `index.html` or client-side JavaScript.
