# Sandeep Yadav — Premium Portfolio

A standalone responsive portfolio built with pure HTML, CSS and JavaScript.

Includes:
- Premium glassmorphism UI and animated gradient hero
- Stable typing headline
- Dark/light mode with localStorage persistence
- Accessible mobile navigation
- Scroll reveal animations
- Active navigation and back-to-top
- Featured projects, skills, professional focus and journey
- 10th/12th percentage-only education details
- B.Tech / AKTU
- LinkedIn, Instagram, WhatsApp, Linktree, GitHub and email
- SEO metadata and Open Graph metadata
- Custom 404 page
- No external libraries or build step required
